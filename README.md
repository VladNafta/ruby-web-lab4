# Лабораторна робота №4. Ruby. Старт

Мікрозадачі на Ruby: робота з рядками, введення/виведення, цикли та прості алгоритми.

| Файл | Завдання |
|---|---|
| `task1.rb` | «Привіт, ясен світ!», змінні, `gets`, підстановка `#{}`, `capitalize`, `upcase` |
| `task2.rb` | найбільший простий множник числа 600851475143 |
| `task3.rb` | сума чисел менше 1000, кратних 3 або 5 |
| `task4.rb` | найбільший паліндром із добутку двох тризначних чисел |
| `task5.rb` | сума цифр натурального числа з командного рядка |

## Запуск

Потрібен Ruby 3.x (перевірено на Ruby 3.4.9 в Ubuntu 24.04, встановлений через RVM).

```
ruby task1.rb            # далі ввести ім'я та прізвище
ruby task2.rb
ruby task3.rb
ruby task4.rb
ruby task5.rb 9876543210
```
